Chưa có target an toàn

Phép thử nội bộ gửi GET tới endpoint chỉ dành cho System Admin và kiểm tra ứng dụng cùng SQL Server bằng truy vấn SELECT 1. HTTP 2xx là thành công; redirect, lỗi HTTP hoặc không có phản hồi được ghi là thất bại. AI và email chưa được thử khi chưa có địa chỉ/contract xác nhận.
